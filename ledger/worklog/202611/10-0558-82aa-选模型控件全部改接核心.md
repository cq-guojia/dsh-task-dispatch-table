## Background

用户 2026-11-10 原话：「按理说，核心应该提供了所有的功能。如果他提供的功能不够，他跟我说，我让核心改，不要我们自己去打补丁；如果所有的功能都提供了，我们所有只要选模型的地方，都有核心的一致性。」

本仓两处选模型（任务编辑器 grouped、设置页 cascade）虽已挂核心 `ModelPicker`，但目录、尺寸、布局仍由本仓自供：host `/options` 自己枚举 llm、client 各拼一份 `EditorOption`、两处各转一次 `groups`，宽度与两列 grid 靠覆盖核心内部类的 CSS。首轮在 `dsh-plugin-core@0.35.12` 上定位 5 个必须由核心补的缺口（路由鉴权、注入时机、cascade row 类名、旧值保真、目录刷新），只升级依赖不改代码，把缺口交给用户转核心。

核心提交 `499c6ee7` 发版 `v0.35.13` 逐条修掉这 5 项；用户随后要求「再取一下新的核心版本……没有问题就做相应的调整」。

## Process

1. 版本：npmjs `dist-tags.latest` 一度停在 `0.35.12`（`pnpm view` 读的是本地 metadata 缓存），直查官方 registry 已是 `0.35.13`；`pnpm add dsh-plugin-core@0.35.13` 装成，`package.json` → `^0.35.13`，`pnpm-workspace.yaml` 自动加 `minimumReleaseAgeExclude`。
2. 核实 `0.35.13` 实现本体：`src/host/index.ts`（`authorize` / `getLlm` / `inject(['webServer'])` / 403-503-500 收口）、`src/ui/infra/host-data.ts`（`refreshModelCatalog` Promise + no-store + in-flight 合并）、`src/ui/inputs/ModelPicker.ts`（`className` 归位 row + 三条类名轴）、`src/ui/inputs/picker-logic.ts`（`retainSelectedValue`）；`README.md` / `docs/help/integration.md` 已改两段式接线。对照 `v0.35.12` 确认 5 项全清；`v0.35.12` 相对 `v0.35.11` 只改分页尺寸档。
3. 本仓接线：新增 `src/model-catalog-route.ts`；`src/index.ts` 的 `apply` 注册 `serveModelCatalog`（守卫复用 `isTrustedDispatchRequest`，`getLlm` 传带 try/catch 的安全取值函数），`/options` 删 models 段；`src/client/index.ts` 的 `apply` 改 `connectHost(ctx, { modelsPath })`；`src/client/settings-config-block.tsx` 挂载调 `refreshModelCatalog()`。
4. 删本仓自拼：`modelGroupsOf()` / `modelGroups()` / `encodeModelValue` / `fetchModelOptions` / `ModelOption` / `EditorOptions.models` 全删；两处 `ModelPicker` 不再传 `groups` / `degraded`。
5. 尺寸与布局改走核心轴：`task-editor.tsx` 用 `width: PROMPT_SELECT_MODEL`（clamp 原样透传）；`settings-config-block.tsx` 用 `rowClassName` + `className`；`task-editor-css.ts` 删 `.dsh-tdt-ed-model`，两列规则改用双类选择器 `.dsh-tdt-model-pair.dshpc-picker__row`（压过核心 `__row` 的 flex，避免注入顺序依赖）。
6. 踩坑：`task-editor-css.ts` 是 TS 模板字符串，注释里写反引号会提前终止字符串 → `tsc` 报 `TS1005`；去掉反引号后 `pnpm run build` 通过。
7. 值口径：核心目录值 `${provider.id}/${model.id}`，与 `src/dispatch.ts` 的 `lookupProvider` / `llm-first` 一致；旧 `/options` 用 `LlmModelInfo.provider`，若两者不同，老值由 `retainSelectedValue` 如实保留（不静默丢）。

`dsh-plugin-core@0.35.13` 五项缺口全清，本仓两处选模型已完全走核心一致性：同一份真实目录、核心尺寸 / 类名轴、核心旧值保真与降级判定。自有模型数据通道与自写触发器尺寸 CSS 已删，仅保留一条挂在核心 `rowClassName` 上的两列等宽布局规则（核心未开放 row 布局参数）。
