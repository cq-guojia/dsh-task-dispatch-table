# 基础信息面板：末行线与行高对齐

> **状态**：✅ 完成封卷（2026-10-03 真机验收通过）
> **口径（已定型）**：[`../design/features/task-expand-panels.md`](../design/features/task-expand-panels.md) §3.1b「纸表格的线与行高」· 两条通用坑已升格 [`../design/ui-style-guide.md`](../design/ui-style-guide.md) §七
> **适用版本**：本仓 0.0.1（宿主 0.2.0-rc.2）

## 一、需求（用户 2026-10-03，三轮真机反馈原话）

1. 「每个任务展开不是分左边和右边吗？你把左边和右边最后一行的最下面那一条线都给我去掉。因为下面有一条统一的虚线，最后一个放在那儿就有点奇怪。」
2. 「你要隐藏掉的是最后一条线，**不是固定的 token 那一条线**。当你有输出的时候，最后一条线就变成了输出，它就不是 token 了。你这两个难道不是一个统一的表格吗？」
3. 「所有的字全都贴上面那条线特别近，离下面那条线特别远。在一行里面是要上下居中的；多行的（前置任务、附件）左边标题应该和右边第一行齐平。」

## 二、三轮定位，各踩一个坑

| 轮 | 我做了什么 | 为什么不对 | 根因 |
|---|---|---|---|
| 1 | 给 `InfoField` 加 class，CSS `:last-child{border-bottom:0}` 去末行缝 | 用户真机「还是有那两条线」 | 底边缝当时写在**内联** `infoGridRowStyle` 里。**内联样式优先级高于任何不含 `!important` 的 CSS** ⇒ 覆盖被盖掉。与 `.dsh-tdt-card` 底色同一个坑 |
| 2 | 底缝挪进 class，用 `:nth-last-child(-n+2)` 收敛末行 | 用户真机「不是固定的 token 那一条线」 | 判定范围**写死在字段区容器**（`.dsh-tdt-info-rec-fields`）内 ⇒ 不管有没有产出物，被去缝的永远是字段区最后一行；而右栏**有产出物时整栏最后一块是产出物区**，Token 并不是末尾 |
| 3 | 判定范围抬到**整栏**：右栏根容器 `.dsh-tdt-info-rec-body` 包住「字段区 + 产出物区」，字段区只在 `:last-child` 时才去缝 | ✅ 线的位置对了，但暴露出下一个问题：字贴上面那条线 | 见 §2.1 |

### 2.1 第三轮「字贴上面那条线」的根因

- 纸表格是**整栏共用一个 grid** + `align-items: stretch`（`task-list.tsx:152`）⇒ 格子高度由**行内最高的那格**决定。
- `.dsh-tdt-info-value` 写了 `line-height: var(--tdt-line-md)`（=20px，对应 13px 字号档），`.dsh-tdt-info-label` **没写行高**、只继承宿主 ⇒ **两格行盒不等高**。
- 矮的那格内容被**顶对齐** ⇒ 看着「贴上边线、离下边线远」，且两格基线不齐（用户第 3 条反馈）。

## 三、落码点

| 改动 | 位置 |
|---|---|
| 两格统一行高（底缝 + `line-height: var(--tdt-line-md)` 都走 class） | `task-list.tsx:157` |
| 末行去缝：左栏字段区 / 右栏"字段区是整栏最后一块时" | `task-list.tsx:162` |
| 右栏根容器包住字段区与产出物区（让 `:last-child` 能判整栏） | `task-list.tsx:1218` / `:1219` |
